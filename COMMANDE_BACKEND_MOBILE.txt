# =====================================================
# COMMANDE POUR BACKEND ACCESSIBLE DEPUIS TÉLÉPHONE
# =====================================================

# Arrêter le backend actuel (Ctrl+C dans le terminal uvicorn)

# Puis relancer avec --host 0.0.0.0 pour écouter sur toutes les interfaces:
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

# Explication:
# --host 0.0.0.0   = Écoute sur TOUTES les interfaces (local + réseau)
# --host 127.0.0.1 = Écoute SEULEMENT sur localhost (pas accessible depuis téléphone)
